## Sobre o Projeto

A **Calculadora em C** é um projeto desenvolvido com o objetivo de aplicar conceitos fundamentais de lógica de programação e programação estruturada.

O programa permite que o usuário escolha entre **20 operações diferentes** por meio de um menu interativo, envolvendo cálculos matemáticos, conversões de temperatura, cálculo de IMC e áreas de figuras geométricas.

## Funcionalidades Especiais

### Cálculo do IMC

A calculadora possui uma função específica para calcular o **Índice de Massa Corporal (IMC)**.

O usuário informa seu peso e altura, e o programa realiza o seguinte cálculo:

```text
IMC = peso / (altura × altura)
```

Após o processamento, o resultado do IMC é apresentado ao usuário.

### Área de Figuras Geométricas

O projeto possui uma opção específica para o cálculo de áreas de diferentes figuras geométricas.

As figuras disponíveis são:

* Quadrado
* Retângulo
* Triângulo
* Círculo

Cada figura solicita as medidas necessárias para realizar o cálculo correspondente.

## ▶️ Como Executar

Para executar o projeto, é necessário possuir um compilador C instalado no computador.

1. Baixe ou clone este repositório.
2. Abra o arquivo `calculadora.c`.
3. Compile o programa utilizando um compilador compatível com C.
4. Execute o programa.
5. Selecione uma das 20 opções disponíveis no menu.
6. Informe os valores solicitados pelo programa.
7. Visualize o resultado da operação escolhida.
