# Algoritmos-e-Pensamento-Computacional
Projeto desenvolvido na disciplina de Algoritmos e Pensamento Computacional, com foco em lógica de programação, pseudocódigo e linguagem C. Foram abordados condicionais, estruturas de repetição, funções, arrays, structs, arquivos, ponteiros e algoritmos de ordenação como Bubble Sort e Quick Sort, aplicando conceitos na resolução de problemas reais.
