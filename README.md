# Algoritmos e Pensamento Computacional

Projeto desenvolvido na disciplina de **Algoritmos e Pensamento Computacional**, com foco no desenvolvimento da lógica de programação e na resolução de problemas utilizando pseudocódigo e linguagem C.

</div>

---

## Conteúdos Abordados

* Lógica de programação
* Pseudocódigo
* Condicionais
* Estruturas de repetição
* Funções
* Arrays
* Structs
* Arquivos
* Ponteiros
* Algoritmos de ordenação

Também foram abordados algoritmos como **Bubble Sort** e **Quick Sort**, aplicando os conceitos estudados na resolução de problemas.
